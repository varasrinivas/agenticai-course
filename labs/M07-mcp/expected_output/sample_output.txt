================================================================================
KEY PATTERNS TO VERIFY
================================================================================

1. SERVER STARTUP:
   The server logs to STDERR (not stdout). Stdout is reserved for JSON-RPC.
   You should see "Starting UCC Filing MCP Server..." on stderr.

2. TOOL LISTING:
   The client should discover 2 tools: search_ucc_filings and get_filing.
   Each tool has a name, description, and input schema.

3. RESOURCE LISTING:
   The client should discover 2 static resources (ucc://filings, ucc://stats)
   and 1 resource template (ucc://filing/{filing_number}).

4. TOOL CALLS:
   Tool calls return content blocks with type "text".
   - search with state="Texas" returns 1 filing (Lone Star Energy Solutions LP)
   - get_filing with a valid number returns the full JSON
   - search with a nonexistent debtor returns "No filings found"

5. RESOURCE READS:
   Resource reads return contents with a text property.
   - ucc://stats returns JSON with filing counts and state list
   - ucc://filings returns a text index of all 11 filings

6. HANDSHAKE:
   The client performs initialize/initialized before any tool/resource calls.
   This is handled automatically by ClientSession (Python) or client.connect() (JS).
