================================================================================
KEY PATTERNS TO VERIFY
================================================================================

1. PARALLEL DISPATCH (Step 1):
   Claude sends MULTIPLE tool_use blocks in one response.
   Your code processes ALL of them and sends ALL results back together.
   Look for: "Processed N tool calls in this turn" in the output.

2. SEQUENTIAL CHAINING (Step 2):
   Claude calls tool 1, gets results, then calls tool 2, gets results, etc.
   Each turn has exactly ONE tool call. The chain spans MULTIPLE turns.
   Look for: "Total tool calls: N across N turns" in the output.

3. TOOL SELECTION (Step 3):
   With 5 tools available, Claude picks the right ones for each query.
   Some queries need 2 tools, some need 3-4. Claude decides the order.
   Look for: varied tool combinations depending on the query.

4. TOOL DISPATCHER:
   All 5 tools route through a single dispatcher (dict/object mapping).
   Unknown tool names are caught and reported as errors.

5. AGENT LOOP:
   Same core pattern as M05: while loop, check stop_reason, act accordingly.
   The loop naturally supports both parallel and sequential patterns.
