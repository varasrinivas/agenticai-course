KEY PATTERNS TO VERIFY
================================================================================

1. WORKING MEMORY:
   - Memory persists across turns within a session
   - get_context() correctly formats all entries for the system prompt
   - Append-style keys (findings_so_far, search_history) accumulate items
   - to_dict() / from_dict() enable serialization/deserialization

2. EPISODIC MEMORY:
   - ChromaDB stores episode summaries as vectors
   - recall() finds semantically similar past research
   - Similarity scores show the most relevant episodes first
   - New episodes can be stored and immediately recalled

3. PROCEDURAL MEMORY:
   - Pattern matching identifies relevant workflows based on triggers
   - Agent follows the procedural steps in order
   - Multiple patterns can match a single task (e.g., entity_search + risk_assessment)

4. ORCHESTRATION:
   - The agent checks procedural memory FIRST for workflow guidance
   - Then checks episodic memory for relevant past experience
   - Uses working memory throughout to track state
   - Stores completed sessions as new episodes for future recall

5. CROSS-SESSION LEARNING:
   - Session 2 recalls Session 1 as relevant past experience
   - The agent compares current findings to historical data
   - Each session enriches the episodic memory for future sessions
