NOTE FOR THE STUDENT

That BLOCKER is the point of the exercise, not a bug in the lab.

The first run is SUPPOSED to fail this check, because the default
data-migrator prompt does not force `null_as` and Claude will often let it
default. Fix it in the subagent definition, re-run phase 3, and re-validate:

    python coordinator.py --phase data
    python coordinator.py --phase validate

The second run should show `NULLS OK  EMPTY OK` on ucc_debtor and
`Blockers: 0`.

If your FIRST run came back clean, do not celebrate -- check that the
validator actually ran. An empty defect list and a validator that never
executed look identical in the JSON.
