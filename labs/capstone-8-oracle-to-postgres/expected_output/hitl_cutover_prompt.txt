WHAT TO NOTICE

way past is decoration.

Also note what the gate is NOT: it does not ask the model whether cutover
seems reasonable. Self-approval is not approval. The only thing that opens
this gate is a person typing --approve-cutover, which sets an environment
variable the agent process can read and cannot write.
