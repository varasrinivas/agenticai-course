   Hybrid captures the best of both via reciprocal rank fusion.

   Claude scores each passage for relevance 0-10 with explanations.
   After re-ranking, the most directly relevant passages rise to the top.
   Position changes show that re-ranking adds value beyond initial retrieval.

   HyDE generates a hypothetical answer that uses domain terminology,
   improving retrieval by matching the "answer space" instead of the
   "question space."
   Multi-query generates 3 diverse queries to cast a wider net.

4. PIPELINE COMPARISON:
   Advanced RAG retrieves MORE relevant sources (draws from broader pool).
   Advanced RAG answers are more comprehensive and accurate.
   The improvement is most visible on ambiguous or conceptual queries.

5. PIPELINE STAGES:
   Transform (HyDE + multi-query) -> Retrieve (hybrid) -> Re-rank (Claude) -> Generate
   Each stage adds measurable improvement over naive RAG.
