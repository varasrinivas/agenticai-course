================================================================================
KEY PATTERNS TO VERIFY
================================================================================

1. TOOL CALL FLOW:
   Your code calls Claude -> Claude returns stop_reason="tool_use" ->
   Your code executes the tool -> Your code sends tool_result back ->
   Claude returns stop_reason="end_turn" with final text

2. MULTI-TOOL:
   Claude may request MULTIPLE tools in a single response.
   Your code must process ALL tool_use blocks and send ALL results back.

3. ERROR RECOVERY:
   When a tool returns an error (unknown city, division by zero),
   the error is sent back as a tool_result. Claude reads it and
   explains the problem in natural language. The agent does NOT crash.

4. NO-TOOL CASE:
   When no tool is needed, Claude responds directly with stop_reason="end_turn"
   on the very first call. The agent loop exits immediately.

5. AGENT LOOP:
   The while loop runs until Claude says "end_turn" or MAX_TURNS is reached.
   Each iteration: API call -> check stop_reason -> act accordingly.
