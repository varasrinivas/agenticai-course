What Is Gemini CLI?

Analogy First

Before Gemini CLI, talking to an AI was like calling a consultant on the phone: you described your problem in words, they gave you advice in words, and you had to go away and actually do the work yourself. Gemini in the browser is still that phone call — helpful, but disconnected from your actual codebase. The pain was always the last mile: "yes, but how do I apply this to my specific file?" Gemini CLI closes that gap. It's like having that consultant sit down at your workstation — they can open your files, read your error logs, run your tests, and commit the fix. The conversation and the action happen in the same place.

Technical Definition

Gemini CLIOpen-source terminal client at github.com/google-gemini/gemini-cli. Uses the Gemini API under the hood; ships with built-in tools for filesystem access, shell execution, and web search. — an open-source, terminal-based AI agent backed by Google's Gemini models. It differs from the browser Gemini UI in one fundamental way: it has tools. A tool is a function the model can call during a conversation — read a file, run a command, search the web. This makes it an agent rather than a chatbot.

Key distinction: Gemini in the browser receives text and returns text. Gemini CLI receives text, uses tools to interact with your computer, and returns both text and actions. The model decides when to use tools without you having to ask.

Free tier: 1,500 requests/day · 10 requests/min · Gemini 2.5 Flash model · No credit card required — just a Google account.

Architecture: How Gemini CLI Works

When you type a prompt, Gemini CLI sends it to the Gemini model along with available tool definitions. The model responds with either text or a tool call. The CLI executes the tool, sends the result back, and the model continues. This loop repeats until the task is done.

Why It Matters — Concrete Numbers

A typical developer workflow with browser AI: describe file (2 min) → paste relevant code (3 min) → get suggestion (30s) → manually apply changes (5 min) → run tests to check (2 min) → repeat. That's 12+ minutes per iteration cycle.

With Gemini CLI on a moderately complex bug: one prompt like @src/auth.js The login function is failing for users with special characters in their email — read the file, find the bug, fix it, and confirm — and the agent reads the file, identifies the regex issue, patches it, and tells you what it changed. Under 90 seconds. The bottleneck shifts from your hands to the model's inference time.

This 8x speed difference compounds over a full workday. The point isn't to replace engineering judgment — it's to remove the mechanical steps that slow you down while you're thinking.

Windows Installation

🪟 Windows First — Mac/Linux in secondary tab

This section walks through the 4 steps to get Gemini CLI running on Windows. Step 2 (execution policy) is the single most common blocker — don't skip it even if Node.js is already installed.

Check / Install Node.js

Open Windows Terminal or PowerShell and check whether Node.js is already installed. You need v18 or higher (v20 LTS is ideal).

WHAT: Prints your Node.js version. If it's missing or below v18, use winget to install the LTS version.
PowerShell
# Check if Node.js is installed
node --version
# Expected output: v18.x.x, v20.x.x, or higher

# If not installed (or below v18), run:
winget install OpenJS.NodeJS.LTS

# Alternative: download the Windows Installer (.msi) from nodejs.org/en/download
# Then: CLOSE and REOPEN your terminal to update PATH

# Verify after install
node --version   # Should now show v20.x.x or similar
npm --version    # Should show 10.x.x or higher
GOTCHA

After installing Node.js, you must close and reopen your terminal. PowerShell caches the PATH at startup — a new install won't be found until you start a fresh session. This trips up ~40% of Windows first-timers.

✅
Checkpoint 1 — Node.js ready Running node --version prints v18.x.x or higher. If you see "command not found" or a version below 18, re-run the winget command and reopen your terminal.

Fix PowerShell Execution Policy #1 Windows Blocker

Windows PowerShell ships with execution policyPowerShell's script execution policy controls which scripts can run. "Restricted" (default) blocks all scripts including npm-installed CLIs. "RemoteSigned" allows locally-created scripts and remotely-downloaded scripts signed by a trusted publisher. set to Restricted by default — this silently prevents npm-installed command-line tools (like Gemini CLI) from running. If you skip this step, you'll install Gemini CLI successfully but get a cryptic "cannot be loaded" error when you try to run it.

WHAT: Checks your current policy and, if Restricted, changes it to RemoteSigned for your user only (no admin required).
WHY: RemoteSigned allows scripts signed by trusted publishers (which npm packages are) while still blocking unsigned scripts from the internet. This is the security-appropriate setting for developers.
PowerShell
# Check your current execution policy
Get-ExecutionPolicy
# Common outputs: Restricted (default), RemoteSigned, Unrestricted, Bypass

# If you see "Restricted", run this fix (no admin required):
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
# When prompted: type "Y" and press Enter

# Verify the fix:
Get-ExecutionPolicy -Scope CurrentUser
# Should now show: RemoteSigned
GOTCHA

If your company manages your machine via Group Policy, Set-ExecutionPolicy may fail with "access denied." In that case, run PowerShell as Administrator, or use the -Scope Process flag (applies only to the current session): Set-ExecutionPolicy RemoteSigned -Scope Process

Install Gemini CLI

Install the Gemini CLI globally using npm. The -g flag installs it to your global npm bin directory, making the gemini command available everywhere.

WHAT: Downloads and installs @google/gemini-cli from the npm registry. Adds `gemini` to your PATH.
GOTCHA: If `gemini` isn't found after install, your npm global bin directory may not be in PATH. The `npm bin -g` command shows you where it is.
PowerShell
# Install Gemini CLI globally
npm install -g @google/gemini-cli

# Verify the install
gemini --version
# Expected: something like 0.1.x or 1.x.x

# If "gemini: command not found" after closing/reopening terminal:
npm bin -g
# This prints the global bin path — add it to your PATH manually if needed
# Common paths: C:\Users\YourName\AppData\Roaming\npm
What Just Happened?

npm downloaded the @google/gemini-cli package and placed the gemini executable in your global npm bin directory. The -g flag is what makes it accessible as a command anywhere, not just inside one project folder.

✅
Checkpoint 2 — Gemini CLI installed Running gemini --version prints a version number. If you see "command not found," close/reopen your terminal. If it still fails, check npm bin -g and add that directory to your PATH.

Authenticate with Google

Run gemini with no arguments to start the interactive REPLRead-Eval-Print Loop — an interactive session where you type a command, the program executes it, prints the result, and waits for the next input. The Gemini CLI REPL is your main interface for all agent work. and trigger the OAuthOpen Authorization — an industry-standard protocol for delegating access without sharing passwords. When Gemini CLI opens your browser, it's using OAuth to get a token that says "this terminal app can access Gemini on behalf of this Google account." login flow.

WHAT: Opens your browser, sends you to Google's OAuth consent screen, and stores an auth token locally after you approve.
WHY: The free tier uses your Google account identity for rate-limit tracking. No credit card, no API key — just your existing Google account.
PowerShell
# Start Gemini CLI (triggers browser auth on first run)
gemini

# What happens:
# 1. Your default browser opens → Google sign-in page
# 2. Sign in with your Google account
# 3. Click "Allow" on the permissions screen
# 4. Browser shows "Authentication successful — you may close this tab"
# 5. Terminal shows the Gemini CLI prompt:
#    > |
# You're now connected. Type your first prompt!
GOTCHA — Browser Doesn't Open?

Some systems (especially headless or WSL environments) can't open a browser automatically. Look in your terminal for a line like Please open this URL in your browser: https://accounts.google.com/o/oauth2/... — copy and paste it manually. If auth keeps failing, jump to API Key Authentication.

✅
Checkpoint 3 — Authenticated Running gemini shows the > prompt without redirecting to a browser (auth is cached). Type /quit to exit. If you still see the browser auth every time, check that your home directory is writable — the token is stored in ~/.gemini/.

On Mac and Linux, the most common blocker is Node.js version — the system may have an old version installed. Use nvm to manage versions cleanly.

Install Node.js via nvm

bash
# Install nvm (Node Version Manager)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash

# Reload your shell config

# OR:
source ~/.zshrc      # If using zsh (default on modern macOS)

# Install and use the LTS version of Node.js
nvm install --lts
nvm use --lts

# Verify
node --version    # Should show v20.x.x or higher
npm --version
GOTCHA

On macOS, if you installed Node.js via Homebrew previously, you may have a conflict. Run which node to confirm it's pointing to the nvm-managed version (should be something like /Users/you/.nvm/versions/node/v20.x.x/bin/node).

# Verify

# Start and authenticate

Your First Commands

You're authenticated and at the > prompt. These 5 commands give you a working mental model of what Gemini CLI can do. Run them in order.

  • 1. Basic question Test that the model is responding. Ask something with a deterministic answer.
  • 2. File reference (@file) Ask the model to read and reason about a file in your current directory.
  • 3. /help List all available slash commands built into the CLI.
  • 4. Web search Ask about current information — the model uses built-in Google Search.
  • 5. /quit or Ctrl+C Exit the REPL cleanly.

Command-by-Command Breakdown

Basic Question

Gemini CLI prompt
> What day of the week will January 1st 2027 fall on?

What the model does: Reasons about the calendar. No tools needed — pure language model reasoning. Expected: "January 1st, 2027 will fall on a Friday."

File Reference with @

The @filename syntax tells Gemini CLI to read that file and include it as context. The file must exist in your current working directory or you can use an absolute path.

WHAT: The @ prefix is a built-in tool trigger. Gemini reads the file content before sending your prompt to the model.
Gemini CLI prompt
> @package.json What dependencies does this project use?

# If you don't have a package.json, create a minimal one first:
# (exit Gemini CLI with /quit, then in PowerShell:)
echo '{"name":"test","dependencies":{"express":"^4.18.0","axios":"^1.6.0"}}' > package.json
# Then run: gemini
# Then type: @package.json What dependencies does this project use?

Expected: The model lists express and axios, explains what each does, and may suggest version update considerations.

Slash Commands — /help

Gemini CLI prompt
> /help

Expected output: A formatted list of all slash commands. Key ones to note: /chat save, /chat resume, /tools, /model, /quit. Slash commands are CLI operations — they don't go to the model.

Web Search (Built-in)

WHAT: Gemini CLI has Google Search built in as a tool. The model decides when to use it — for questions about current info it will automatically search.
Gemini CLI prompt
> What is the latest LTS version of Node.js?

What you'll see: A brief "searching..." indicator, then a response with the current LTS version pulled from the web. The model cites its sources. This is different from the browser Gemini — the search happens in real-time against the live web.

Exit the REPL

Gemini CLI prompt
> /quit
# OR press Ctrl+C twice

Your conversation history is saved automatically. You can resume a session with /chat resume in the next session.

When You See "Gemini is thinking..." vs. Multiple Steps

"Thinking" (single pause) — the model is doing language reasoning without tools. Pure text response incoming.

Multiple visible steps (reading file → running command → reading output) — the model is executing a multi-tool agent loop. Each step appears in the terminal. This is normal and expected for complex requests.

Long pause with no output — likely a network issue or rate limit. Hit Ctrl+C and try again. Check the troubleshooting table below if it persists.

How to Switch Models

Three ways to change the model:

  1. Command flag: gemini --model gemini-2.5-pro — applies to that session only
  2. Inside session: /model gemini-2.5-pro — switches mid-conversation
  3. GEMINI.md config: Add model: gemini-2.5-pro to your project's GEMINI.md — persistent, covered in M02

For free-tier users: gemini-2.5-flash is the only available model. Attempting to use Pro will return a "model not available" error until you add a paid API key.

Alternative: API Key Authentication

If OAuth doesn't work (corporate firewalls, Workspace restrictions, WSL without browser access), use an API keyA string credential that identifies and authenticates your application to the Gemini API. Unlike OAuth tokens, API keys don't represent a user — they represent an application. API keys can be created, revoked, and rate-limited independently of any Google account. instead. API keys also unlock higher rate limits and Pro model access.

Get Your API Key from Google AI Studio

  1. Go to aistudio.google.com
  2. Click "Get API Key" in the top-left sidebar
  3. Click "Create API Key"
  4. Copy the key (it starts with AIza...)
Never Commit API Keys to Git

Set your key as an environment variable — never paste it directly into code or config files that get committed. The environment variable approach below is safe.

Set the Environment Variable

WHAT: The first command sets GEMINI_API_KEY for the current session only. The second persists it in your Windows user environment so it survives reboots.
PowerShell
# Set for current session only (temporary):
$env:GEMINI_API_KEY = "AIzaSy_YOUR_KEY_HERE"

# Set permanently (survives terminal restarts and reboots):
[System.Environment]::SetEnvironmentVariable(
  "GEMINI_API_KEY",
  "AIzaSy_YOUR_KEY_HERE",
  "User"
)

# Verify it's set:
echo $env:GEMINI_API_KEY

# Now start Gemini CLI — it will use the API key automatically:
gemini
GOTCHA

The permanent SetEnvironmentVariable with "User" scope writes to your Windows user profile, but it doesn't affect your current PowerShell session. After running it, close and reopen your terminal before testing with echo $env:GEMINI_API_KEY.

bash
# Set for current session only:
export GEMINI_API_KEY="AIzaSy_YOUR_KEY_HERE"

# Persist across sessions (add to your shell config):
echo 'export GEMINI_API_KEY="AIzaSy_YOUR_KEY_HERE"' >> ~/.bashrc
# Or if using zsh:
echo 'export GEMINI_API_KEY="AIzaSy_YOUR_KEY_HERE"' >> ~/.zshrc

# Reload:
source ~/.bashrc

# Verify:
echo $GEMINI_API_KEY

# Start Gemini CLI:
gemini
OAuth vs API Key — When to Use Each
  • OAuth (default): Best for personal laptops, individual use, learning. Free, no setup. 1,500 req/day limit.
  • API Key: Best for corporate environments, CI/CD pipelines, teams, or when you need Pro model access. Configurable rate limits. Required for gemini-2.5-pro.

Common Issues & Fixes

If something isn't working, find your error in this table. Windows-specific issues are marked.

Error / Symptom Platform Fix
gemini: command not found All Close and reopen your terminal. Then run npm bin -g to find the global bin path and verify it's in your PATH. On Windows: check C:\Users\YourName\AppData\Roaming\npm is in system PATH.
cannot be loaded because running scripts is disabled 🪟 Windows only Run Set-ExecutionPolicy RemoteSigned -Scope CurrentUser in PowerShell. See Step 2 in the Windows install section above.
Google Workspace account not supported / access denied All Your company's IT policy blocks OAuth for third-party apps. Use API key authentication instead — see the API Key section above.
SSL certificate error / UNABLE_TO_VERIFY_LEAF_SIGNATURE All You're behind a corporate proxy with SSL inspection. Set: $env:NODE_EXTRA_CA_CERTS = "C:\path\to\corporate-cert.pem" (Windows) or export NODE_EXTRA_CA_CERTS=/path/to/cert.pem (Mac/Linux). Ask your IT team for the certificate file.
EADDRINUSE port already in use All Another MCP server or process is using the port Gemini CLI needs. Run Get-Process -Id (Get-NetTCPConnection -LocalPort 3000).OwningProcess (Windows) or lsof -i :3000 (Mac) to find and kill it.
Rate limit exceeded / 429 Too Many Requests All Free tier: 10 requests/minute. Wait 60 seconds and retry. If you hit the daily 1,500 limit, add an API key for higher limits or wait until midnight Pacific time for the counter to reset.
Model "gemini-2.5-pro" not available All Free tier (OAuth) only includes Gemini 2.5 Flash. Add a paid API key from aistudio.google.com to access Pro models.
Node version too old / requires Node 18+ All Windows: winget install OpenJS.NodeJS.LTS then reopen terminal. Mac/Linux: nvm install --lts && nvm use --lts. Verify with node --version.
