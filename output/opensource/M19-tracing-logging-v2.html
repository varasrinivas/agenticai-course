Why Tracing Matters

The Flight Data Recorder Analogy

Before the pain: Commercial aircraft have flown for decades without crashes going unexplained, because every flight records hundreds of parameters — airspeed, altitude, control surface positions, engine metrics — to a tamper-proof black box. Investigators can reconstruct the exact sequence of events that led to any incident, even if the crew cannot speak for themselves.

The pain without it: Now imagine an airline that decides black boxes are too expensive to maintain, too much disk space, too much operational overhead. For years everything is fine. Then a plane goes down and the investigators have nothing — no altitude record, no control inputs, no engine data. The crash will never be fully explained, the root cause will never be fixed, and the same failure will recur.

The mapping: Your agent is the aircraft. Every LLM call, every tool invocation, every loop iteration is a sensor reading. Without a structured traceA structured trace is a machine-readable record of every operation your agent performed during a single run, stored in a format (JSON, OTLP) that can be queried, visualized, and replayed. Unlike print() logs, traces capture causality — which call triggered which — not just sequence. , a production failure is an unexplained crash. You have a result (wrong answer, timeout, exception) but no flight data to reconstruct how you got there.

A Real Production Failure

An entity resolution agent processes 30,000 UCC filings per night. In week three of production, the data team notices a pattern: entity pairs that share a registered agent but differ in state are being merged with 0.91 confidence when they should be flagged as distinct. Nobody can explain it. The system prompt hasn't changed. The model is the same.

Two engineers spend four days adding print statements, replaying queries, and guessing. The root cause: a tool called lookup_registered_agent started returning an extra field with a default value of "", and the LLM was treating that empty string as a match signal. The fix takes six minutes. The diagnosis took four days — because there were no traces.

What to Trace in an Agent

Definition: Trace vs. Log vs. Span

A traceA trace is the complete record of a single agent run from start to finish — every LLM call, tool call, and loop iteration, plus their causal relationships. One query = one trace. A trace is composed of spans. is the top-level record for a single agent run. A spanA span is a single timed operation within a trace — one LLM call, one tool invocation, one agent loop iteration. Spans can be nested: a parent span (agent loop) contains child spans (LLM call, tool call). Each span has a start time, end time, and arbitrary key-value attributes. is a timed unit of work within that trace. A log is a timestamped event — a point in time with no duration. Traces give you causality ("this LLM call happened because the previous tool returned X"), logs give you events ("error occurred at 14:03:22"), and spans give you latency distribution.

Four data categories must be captured in every production agent trace:

  • Tool calls: name, input arguments, output value, latency in ms, success/error status
  • LLM turns: model name, prompt token count, completion token count, finish_reason, latency in ms
  • Agent loop iterations: iteration number, tools called this iteration, exit reason (tool result / max iterations / stop signal)
  • Errors: exception type, message, stack trace, whether retry was attempted, final retry outcome

class AgentTrace:
    run_id: str

    errors: list[ErrorEvent] = field(default_factory=list)
    final_answer: Optional[str] = None

    def finish(self, answer: str):
        self.ended_at = time.time()
        self.final_answer = answer

    def duration_ms(self) -> float:
        if self.ended_at:
            return (self.ended_at - self.started_at) * 1000
        return 0.0

    def to_jsonl(self) -> str:
        """Serialize to a single JSON Lines record."""
        d = {
            "run_id": self.run_id,
            "query": self.query,
            "started_at": self.started_at,
            "ended_at": self.ended_at,
            "duration_ms": self.duration_ms(),
            "tool_calls": [e.to_dict() for e in self.tool_calls],
            "llm_turns": [e.to_dict() for e in self.llm_turns],
            "loop_iterations": [e.to_dict() for e in self.loop_iterations],
            "errors": [e.to_dict() for e in self.errors],
            "final_answer": self.final_answer,
        }
        return json.dumps(d)

Definition: Structured Logging

Structured loggingStructured logging emits log events as machine-readable key-value pairs (JSON) rather than human-readable strings. Instead of logger.info("Tool search_filings took 124ms"), you emit {"event": "tool_call", "name": "search_filings", "latency_ms": 124}. This makes every field queryable without regex parsing. is the practice of emitting log events as key-value pairs (JSON) rather than free-form strings. print("Tool took 124ms") is a string. log.info("tool_call", name="search_filings", latency_ms=124) is structured. The difference: structured events are queryable without regex. You can ask "show me all tool calls where latency_ms > 500" in seconds, not hours.

# WHAT: Wraps an agent loop and emits a structured event for every
#       LLM call and tool invocation
# GOTCHA: Bind run_id at the start; every log call inside the loop
#         will automatically include it — no manual threading required

def run_agent_with_logging(query: str, tools: list, tool_handlers: dict) -> str:
    run_id = str(uuid.uuid4())[:8]
    bound_log = log.bind(run_id=run_id, query=query[:60])
    bound_log.info("agent_start", model="mistral")

    messages = [{"role": "user", "content": query}]
    iteration = 0
    max_iterations = 10

    while iteration < max_iterations:
        iteration += 1
        bound_log.info("loop_iteration", iteration=iteration)

        # ── LLM call with timing ─────────────────────────────────────────
        t0 = time.time()
        try:
            response = client.chat.completions.create(
                model="mistral",
                messages=messages,
                tools=tools,
                temperature=0,
            )
        except Exception as exc:
            bound_log.error("llm_call_failed",
                iteration=iteration,
                error_type=type(exc).__name__,
                message=str(exc),
            )
            raise
        llm_ms = (time.time() - t0) * 1000
        choice = response.choices[0]

        bound_log.info("llm_turn",
            iteration=iteration,
            model="mistral",
            prompt_tokens=response.usage.prompt_tokens,
            completion_tokens=response.usage.completion_tokens,
            finish_reason=choice.finish_reason,
            latency_ms=round(llm_ms, 1),
        )

        # ── Check for final answer ───────────────────────────────────────
        if choice.finish_reason == "stop":
            answer = choice.message.content
            bound_log.info("agent_stop",
                iteration=iteration,
                answer_len=len(answer or ""),
            )
            return answer

        # ── Handle tool calls ────────────────────────────────────────────
        messages.append(choice.message)
        tool_calls = choice.message.tool_calls or []

        for tc in tool_calls:
            fn_name = tc.function.name
            import json
            args = json.loads(tc.function.arguments)

            t1 = time.time()
            try:
                result = tool_handlers[fn_name](**args)
                tool_ms = (time.time() - t1) * 1000
                bound_log.info("tool_call",
                    tool=fn_name,
                    args=args,
                    latency_ms=round(tool_ms, 1),
                    success=True,
                )
            except Exception as exc:
                tool_ms = (time.time() - t1) * 1000
                bound_log.error("tool_call_failed",
                    tool=fn_name,
                    args=args,
                    latency_ms=round(tool_ms, 1),
                    error_type=type(exc).__name__,
                    message=str(exc),
                )
                result = f"Error: {exc}"

            messages.append({
                "role": "tool",
                "tool_call_id": tc.id,
                "content": str(result),
            })

    bound_log.warning("max_iterations_reached", max=max_iterations)
    return "Agent reached max iterations without a final answer."

// WHAT: pino structured logger for agent loop instrumentation
// WHY:  pino is the fastest Node.js structured logger; its child() API

const pino = require('pino');
const OpenAI = require('openai');

const logger = pino({

  timestamp: pino.stdTimeFunctions.isoTime,
  formatters: {
    level(label) { return { level: label }; },
  },
});

const client = new OpenAI({
  baseURL: 'http://localhost:11434/v1',
  apiKey: 'ollama',

// ── Agent wrapper ──────────────────────────────────────────────────────
// WHAT: Same wrapper as the Python version — bind run_id as child logger
// GOTCHA: child loggers in pino are cheap clones — they inherit all
//         fields from the parent, so run_id flows through automatically

async function runAgentWithLogging(query, tools, toolHandlers) {
  const runId = Math.random().toString(36).slice(2, 10);
  const log = logger.child({ runId, query: query.slice(0, 60) });

  log.info({ event: 'agent_start', model: 'mistral' });

  const messages = [{ role: 'user', content: query }];
  let iteration = 0;
  const maxIterations = 10;

  while (iteration < maxIterations) {
    iteration++;
    log.debug({ event: 'loop_iteration', iteration });

    // ── LLM call with timing ────────────────────────────────────────
    const t0 = Date.now();
    let response;
    try {
      response = await client.chat.completions.create({
        model: 'mistral',
        messages,
        tools,
        temperature: 0,
      });
    } catch (err) {
      log.error({ event: 'llm_call_failed', iteration, errorType: err.constructor.name, message: err.message });
      throw err;
    }
    const llmMs = Date.now() - t0;
    const choice = response.choices[0];

    log.info({
      event: 'llm_turn',
      iteration,
      model: 'mistral',
      promptTokens: response.usage.prompt_tokens,
      completionTokens: response.usage.completion_tokens,
      finishReason: choice.finish_reason,
      latencyMs: llmMs,
    });

    // ── Final answer ─────────────────────────────────────────────────
    if (choice.finish_reason === 'stop') {
      const answer = choice.message.content;
      log.info({ event: 'agent_stop', iteration, answerLen: (answer || '').length });
      return answer;
    }

    // ── Tool calls ───────────────────────────────────────────────────
    messages.push(choice.message);
    for (const tc of choice.message.tool_calls || []) {
      const fnName = tc.function.name;
      const args = JSON.parse(tc.function.arguments);

      const t1 = Date.now();
      let result;
      try {
        result = await toolHandlers[fnName](args);
        log.info({ event: 'tool_call', tool: fnName, args, latencyMs: Date.now() - t1, success: true });
      } catch (err) {
        log.error({ event: 'tool_call_failed', tool: fnName, args, latencyMs: Date.now() - t1, errorType: err.constructor.name, message: err.message });
        result = `Error: ${err.message}`;
      }

      messages.push({ role: 'tool', tool_call_id: tc.id, content: String(result) });
    }
  }

  log.warn({ event: 'max_iterations_reached', max: maxIterations });
  return 'Agent reached max iterations without a final answer.';
}

  async ({ nameA, nameB }) => {
    // Simple Levenshtein ratio
    const longer = nameA.length > nameB.length ? nameA : nameB;
    const shorter = nameA.length > nameB.length ? nameB : nameA;
    if (longer.length === 0) return 1.0;
    const editDistance = (a, b) => {
      const dp = Array.from({ length: a.length + 1 }, (_, i) =>
        Array.from({ length: b.length + 1 }, (_, j) => (i === 0 ? j : j === 0 ? i : 0))
      );
      for (let i = 1; i <= a.length; i++)
        for (let j = 1; j <= b.length; j++)
          dp[i][j] = a[i-1] === b[j-1] ? dp[i-1][j-1] : 1 + Math.min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]);
      return dp[a.length][b.length];
    };
    return (longer.length - editDistance(longer.toLowerCase(), shorter.toLowerCase())) / longer.length;

def _append_jsonl(path: Path, record: dict) -> None:
    """Append a single JSON record to a .jsonl file atomically."""
    with open(path, "a", encoding="utf-8") as f:
        f.write(json.dumps(record) + "\n")

def trace_agent(func: Callable) -> Callable:
    """
    Decorator that traces a complete agent run.
    Usage: @trace_agent on the top-level run function.
    Output: traces/.jsonl with one event per line.
    """
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        run_id = str(uuid.uuid4())[:8]
        trace_path = TRACE_DIR / f"{run_id}.jsonl"

        # Store context so nested tool/llm helpers can append to same file
        _local.run_id = run_id
        _local.trace_path = trace_path
        _local.iteration = 0

        start = time.time()
        _append_jsonl(trace_path, {
            "event": "run_start",
            "run_id": run_id,
            "function": func.__name__,
            "args_summary": str(args)[:200],
            "timestamp": start,
        })

        try:
            result = func(*args, **kwargs)
            elapsed = (time.time() - start) * 1000
            _append_jsonl(trace_path, {
                "event": "run_end",
                "run_id": run_id,
                "duration_ms": round(elapsed, 1),
                "status": "success",
                "result_summary": str(result)[:200],
            })
            print(f"[trace] {run_id} — {elapsed:.0f}ms — see {trace_path}")
            return result
        except Exception as exc:
            elapsed = (time.time() - start) * 1000
            _append_jsonl(trace_path, {
                "event": "run_end",
                "run_id": run_id,
                "duration_ms": round(elapsed, 1),
                "status": "error",
                "error_type": type(exc).__name__,
                "message": str(exc),
                "stack": traceback.format_exc(),
            })
            raise
        finally:
            _local.run_id = None
            _local.trace_path = None

    return wrapper

# ── Replay utility ───────────────────────────────────────────────────────
# WHAT: Read back a trace file and replay events for post-mortem debugging
# WHY:  You can iterate on a failed run without re-calling the LLM:
#       1. Capture the run trace. 2. Fix the bug. 3. replay_trace() to verify
#       the call sequence was correct before spending tokens re-running.

def replay_trace(run_id: str) -> list[dict]:
    """Load and return all events for a given run_id."""
    trace_path = TRACE_DIR / f"{run_id}.jsonl"
    if not trace_path.exists():
        raise FileNotFoundError(f"No trace found for run_id={run_id}")
    events = []
    with open(trace_path, "r", encoding="utf-8") as f:
        for line in f:
            line = line.strip()
            if line:
                events.append(json.loads(line))
    return events

// WHY:  AsyncLocalStorage is the Node.js equivalent of Python's threading.local()
//       — it propagates context through async/await without passing it explicitly
// GOTCHA: Requires Node.js >= 16.4.0 for AsyncLocalStorage stability

const { AsyncLocalStorage } = require('async_hooks');
const fs = require('fs');
const path = require('path');
const crypto = require('crypto');

const TRACE_DIR = path.join(process.cwd(), 'traces');
if (!fs.existsSync(TRACE_DIR)) fs.mkdirSync(TRACE_DIR, { recursive: true });

const traceContext = new AsyncLocalStorage();

function appendJsonl(filePath, record) {
  fs.appendFileSync(filePath, JSON.stringify(record) + '\n', 'utf8');
}

function traceAgent(fn) {
  return async function (...args) {
    const runId = crypto.randomBytes(4).toString('hex');
    const tracePath = path.join(TRACE_DIR, `${runId}.jsonl`);
    const ctx = { runId, tracePath, iteration: 0 };

    const start = Date.now();
    appendJsonl(tracePath, { event: 'run_start', runId, function: fn.name, timestamp: start });

    return traceContext.run(ctx, async () => {
      try {
        const result = await fn(...args);
        const durationMs = Date.now() - start;
        appendJsonl(tracePath, { event: 'run_end', runId, durationMs, status: 'success', resultSummary: String(result).slice(0, 200) });
        console.log(`[trace] ${runId} — ${durationMs}ms — see ${tracePath}`);
        return result;
      } catch (err) {
        const durationMs = Date.now() - start;
        appendJsonl(tracePath, { event: 'run_end', runId, durationMs, status: 'error', errorType: err.constructor.name, message: err.message, stack: err.stack });
        throw err;
      }
    });
  };
}

function traceTool(toolName) {
  return function (fn) {
    return async function (...args) {
      const t0 = Date.now();
      const ctx = traceContext.getStore();
      try {
        const result = await fn(...args);
        if (ctx) appendJsonl(ctx.tracePath, { event: 'tool_call', runId: ctx.runId, tool: toolName, latencyMs: Date.now() - t0, success: true, resultSummary: String(result).slice(0, 200) });
        return result;
      } catch (err) {
        if (ctx) appendJsonl(ctx.tracePath, { event: 'tool_call', runId: ctx.runId, tool: toolName, latencyMs: Date.now() - t0, success: false, error: err.message });
        throw err;
      }
    };
  };
}

function traceLlmCall({ model, promptTokens, completionTokens, finishReason, latencyMs }) {
  const ctx = traceContext.getStore();
  if (ctx) {
    ctx.iteration++;
    appendJsonl(ctx.tracePath, { event: 'llm_turn', runId: ctx.runId, iteration: ctx.iteration, model, promptTokens, completionTokens, finishReason, latencyMs: Math.round(latencyMs) });
  }
}

function replayTrace(runId) {
  const tracePath = path.join(TRACE_DIR, `${runId}.jsonl`);
  if (!fs.existsSync(tracePath)) throw new Error(`No trace found for runId=${runId}`);
  return fs.readFileSync(tracePath, 'utf8')
    .split('\n')
    .filter(Boolean)
    .map(line => JSON.parse(line));
}

# WHAT: CLI trace viewer for .jsonl trace files
# WHY:  Human-readable call tree without needing Jaeger or LangSmith
# GOTCHA: The ANSI color codes work in any POSIX terminal and in Windows
#         Terminal. They do NOT work in plain cmd.exe — redirect output
#         to a file instead: python trace_viewer.py <run_id> > trace.txt

import sys
import json
from pathlib import Path

# ── ANSI colors ─────────────────────────────────────────────────────────
RESET = "\033[0m"
BOLD  = "\033[1m"
GREEN = "\033[32m"
YELLOW = "\033[33m"
RED   = "\033[31m"
CYAN  = "\033[36m"
DIM   = "\033[2m"

SLOW_THRESHOLD_MS = 2000  # Highlight anything over 2 seconds

def load_trace(run_id: str) -> list[dict]:
    path = Path("traces") / f"{run_id}.jsonl"
    if not path.exists():
        # Try current directory
        path = Path(f"{run_id}.jsonl")
    if not path.exists():
        raise FileNotFoundError(f"Trace file not found for run_id={run_id}")
    events = []
    with open(path, "r", encoding="utf-8") as f:
        for line in f:
            line = line.strip()
            if line:
                events.append(json.loads(line))
    return events

def fmt_ms(ms: float) -> str:
    if ms >= SLOW_THRESHOLD_MS:
        return f"{RED}{BOLD}{ms:.0f}ms ⚠ SLOW{RESET}"
    elif ms >= 500:
        return f"{YELLOW}{ms:.0f}ms{RESET}"
    else:
        return f"{GREEN}{ms:.0f}ms{RESET}"

def print_trace(run_id: str) -> None:
    events = load_trace(run_id)
    print(f"\n{BOLD}{CYAN}══ Trace: {run_id} ══{RESET}")

    for ev in events:
        kind = ev.get("event", "unknown")

        if kind == "run_start":
            print(f"  {BOLD}▶ run_start{RESET}  fn={ev.get('function','?')}")

        elif kind == "run_end":
            status = ev.get("status", "?")
            dur = ev.get("duration_ms", 0)
            color = GREEN if status == "success" else RED
            print(f"  {color}{BOLD}■ run_end{RESET}    status={status}  total={fmt_ms(dur)}")

        elif kind == "llm_turn":
            it = ev.get("iteration", "?")
            ms = ev.get("latency_ms", 0)
            tokens = ev.get("prompt_tokens", 0) + ev.get("completion_tokens", 0)
            fr = ev.get("finish_reason", "?")
            print(f"  {CYAN}  ├─ llm_turn{RESET}   iter={it}  tokens={tokens}  finish={fr}  latency={fmt_ms(ms)}")

        elif kind == "tool_call":
            tool = ev.get("tool", "?")
            ms = ev.get("latency_ms", 0)
            ok = ev.get("success", True)
            marker = f"{GREEN}✓{RESET}" if ok else f"{RED}✗{RESET}"
            err = f"  error={ev.get('error','')}" if not ok else ""
            print(f"  {CYAN}  │  └─ tool{RESET}    {marker} {tool}  latency={fmt_ms(ms)}{err}")

    # ── Summary ─────────────────────────────────────────────────────────
    llm_events = [e for e in events if e.get("event") == "llm_turn"]
    tool_events = [e for e in events if e.get("event") == "tool_call"]
    total_tokens = sum(e.get("prompt_tokens", 0) + e.get("completion_tokens", 0) for e in llm_events)
    slow_tools = [e for e in tool_events if e.get("latency_ms", 0) >= SLOW_THRESHOLD_MS]

    print(f"\n{BOLD}  Summary{RESET}")
    print(f"    LLM turns:    {len(llm_events)}")
    print(f"    Tool calls:   {len(tool_events)}")
    print(f"    Total tokens: {total_tokens}")
    if slow_tools:
        print(f"    {RED}{BOLD}Slow tools ({len(slow_tools)}):{RESET} {', '.join(e.get('tool') for e in slow_tools)}")
    print()

# ── pandas analysis (optional) ───────────────────────────────────────────
def load_into_pandas(run_id: str):
    """Load trace events into a pandas DataFrame for analysis."""
    try:
        import pandas as pd
    except ImportError:
        print("pip install pandas to use this feature")
        return None
    events = load_trace(run_id)
    return pd.DataFrame(events)

if __name__ == "__main__":
    if len(sys.argv) < 2:
        print("Usage: python trace_viewer.py <run_id>")
        sys.exit(1)
    print_trace(sys.argv[1])

// WHAT: CLI trace viewer using chalk for colored output
// WHY:  Same functionality as the Python viewer — pick whichever runtime
//       matches your project's primary language
// GOTCHA: chalk v5 is ESM-only. Use chalk v4 if your project uses CommonJS
//         (require()). Install: npm install chalk@4

const fs = require('fs');
const path = require('path');

// Use chalk if available, fallback to identity functions for no-color mode
let chalk;
try {
  chalk = require('chalk');
} catch {
  const id = (s) => s;
  chalk = { red: { bold: id }, green: id, yellow: id, cyan: id, bold: id, dim: id };
}

const SLOW_THRESHOLD_MS = 2000;

function loadTrace(runId) {
  const filePath = path.join(process.cwd(), 'traces', `${runId}.jsonl`);
  if (!fs.existsSync(filePath)) throw new Error(`Trace file not found for runId=${runId}`);
  return fs.readFileSync(filePath, 'utf8')
    .split('\n')
    .filter(Boolean)
    .map(line => JSON.parse(line));
}

function fmtMs(ms) {
  if (ms >= SLOW_THRESHOLD_MS) return chalk.red.bold(`${ms}ms ⚠ SLOW`);
  if (ms >= 500) return chalk.yellow(`${ms}ms`);
  return chalk.green(`${ms}ms`);
}

function printTrace(runId) {
  const events = loadTrace(runId);
  console.log(`\n${chalk.bold.cyan(`══ Trace: ${runId} ══`)}`);

  for (const ev of events) {
    const kind = ev.event || 'unknown';
    if (kind === 'run_start') {
      console.log(`  ${chalk.bold('▶ run_start')}  fn=${ev.function || '?'}`);
    } else if (kind === 'run_end') {
      const ok = ev.status === 'success';
      const col = ok ? chalk.green.bold : chalk.red.bold;
      console.log(`  ${col('■ run_end')}    status=${ev.status}  total=${fmtMs(ev.durationMs || 0)}`);
    } else if (kind === 'llm_turn') {
      const tokens = (ev.promptTokens || 0) + (ev.completionTokens || 0);
      console.log(`  ${chalk.cyan('  ├─ llm_turn')}   iter=${ev.iteration}  tokens=${tokens}  finish=${ev.finishReason}  latency=${fmtMs(ev.latencyMs || 0)}`);
    } else if (kind === 'tool_call') {
      const marker = ev.success ? chalk.green('✓') : chalk.red('✗');
      const errStr = ev.success ? '' : `  error=${ev.error}`;
      console.log(`  ${chalk.cyan('  │  └─ tool')}    ${marker} ${ev.tool}  latency=${fmtMs(ev.latencyMs || 0)}${errStr}`);
    }
  }

  const llmEvents = events.filter(e => e.event === 'llm_turn');
  const toolEvents = events.filter(e => e.event === 'tool_call');
  const totalTokens = llmEvents.reduce((s, e) => s + (e.promptTokens || 0) + (e.completionTokens || 0), 0);
  const slowTools = toolEvents.filter(e => (e.latencyMs || 0) >= SLOW_THRESHOLD_MS);

  console.log(`\n${chalk.bold('  Summary')}`);
  console.log(`    LLM turns:    ${llmEvents.length}`);
  console.log(`    Tool calls:   ${toolEvents.length}`);
  console.log(`    Total tokens: ${totalTokens}`);
  if (slowTools.length) console.log(`    ${chalk.red.bold(`Slow tools (${slowTools.length}):`)} ${slowTools.map(e => e.tool).join(', ')}`);
  console.log();
}

const runId = process.argv[2];
if (!runId) { console.error('Usage: node traceViewer.js '); process.exit(1); }
printTrace(runId);

A

B
